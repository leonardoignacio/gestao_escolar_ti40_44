//Remover a versão 8 do prisma e instalar a 7
npm uninstall prisma
npm uninstall prisma @prisma/client
npm cache clean --force

//Reinstalar o Prisma 7
npm install prisma@^7.10.1 @prisma/config --save-dev
npm install @prisma/client@^7.10.1
npm install @types/node --save-dev

//iniciar o prisma
npx prisma init --datasource-provider postgresql
npm install pg @prisma/adapter-pg

//Migration
npx prisma migrate dev --name init_database

//Geração do client
npx prisma generate


Fluxo de dados da nossa arquitetura ficará unidirecional e elegante, seguindo esta esteira:

Requisição HTTP ➔ Rota (Express) ➔ Controlador (Regra de Orquestração) ➔ Repositório (Regra de Persistência) ➔ Prisma (ORM) ➔ Neon (PostgreSQL)
