Referência da API

Sistema de Gestão Escolar. Arquitetura RESTful completa com contratos explícitos de dados.

🛡️ Rotas Protegidas (JWT)

A grande maioria dos endpoints exige autenticação. Injete o token no cabeçalho HTTP da seguinte forma:

Authorization: Bearer eyJhbGciOiJIUzI1...

Autenticação

POST /api/auth/login PÚBLICO

Gera o token de acesso JWT com base nas credenciais.

{
  "email": "admin@escola.com",
  "senha": "senhaSegura123"
}

Usuários

Endpoints de gestão de contas de acesso (GET, PUT, DELETE requerem JWT).

POST /api/usuarios PÚBLICO 
{
  "email": "novo.usuario@escola.com",
  "senha": "senhaSegura123",
  "perfilNome": "ADMINISTRADOR"
}

Perfis (Roles)

POST / PUT /api/perfis PROTEGIDO

Cria ou atualiza um papel no sistema de RBAC (Role-Based Access Control).

{
  "nome": "COORDENADOR"
}

Permissões

POST / PUT /api/permissoes PROTEGIDO

Define permissões granulares de acesso a recursos.

{
  "nome": "CRIAR_ALUNO",
  "descricao": "Permite registrar novos alunos na instituição"
}

Alunos

POST /api/alunos PROTEGIDO

Cadastra um aluno. Matrícula obrigatória e única.

{
  "matricula": "2026-001",
  "nome": "Leonardo Ignacio Fernandes",
  "dataNascimento": "1980-05-15"
}

Cursos

POST / PUT /api/cursos PROTEGIDO

Estrutura de dados para criação e atualização de matrizes curriculares.

{
  "nome": "Técnico em Informática",
  "cargaHoraria": 1200,
  "descricao": "Curso técnico focado em desenvolvimento de software e redes."
}

Docentes

POST / PUT /api/docentes PROTEGIDO

O registro (ID corporativo) deve ser único.

{
  "registro": "DOC-2026-001",
  "nome": "Dr. Alan Turing",
  "especialidade": "Algoritmos e Criptografia"
}

Turmas

POST / PUT /api/turmas PROTEGIDO

Relaciona alunos e docentes a um curso específico (Chave Estrangeira cursoId).

{
  "codigo": "TI-40",
  "semestre": "2026.1",
  "turno": "Noturno",
  "cursoId": 1
}

Comportamento RESTful Herdado

Todas as entidades acima (exceto restrições de negócio específicas) suportam as seguintes operações por padrão através do GenericController:

  • GET /api/{entidade} -> Devolve array de registos ativos
  • GET /api/{entidade}/:id -> Devolve detalhe de registo específico
  • PUT /api/{entidade}/:id -> Suporta atualização parcial (PATCH nativo do Prisma)
  • DELETE /api/{entidade}/:id -> Aplica Soft Delete (não apaga dados físicos)
